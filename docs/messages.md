# メッセージ一覧

## 概要
本ドキュメントでは、アプリケーション内で使用されるすべてのメッセージ（エラーメッセージ、成功メッセージ、UIテキスト等）を一覧化します。

## エラーメッセージ

### 認証関連

#### AUTH-ERROR-001: ログイン失敗
- **メッセージ**: 「ログインに失敗しました。もう一度お試しください。」
- **表示箇所**: ログインページ
- **発生条件**: 認証プロバイダーでの認証失敗

#### AUTH-ERROR-002: 認証が必要
- **メッセージ**: 「この機能を利用するにはログインが必要です。」
- **表示箇所**: 認証が必要な機能へのアクセス時
- **発生条件**: 未認証ユーザーが認証必須機能にアクセス

#### AUTH-ERROR-003: セッション期限切れ
- **メッセージ**: 「セッションの有効期限が切れました。再度ログインしてください。」
- **表示箇所**: API呼び出し時
- **発生条件**: トークンの有効期限切れ

## メッセージの実装方針

### 多言語対応
- 現時点では日本語のみ対応
- 将来的に英語対応を検討

### メッセージの管理
- メッセージは定数ファイル（`constants/messages.ts`等）で一元管理
- メッセージIDをキーとして管理し、変更に強い設計とする

### 動的メッセージ
- `{current}`、`{max}`、`{rank}`などの変数は、実際の値に置き換えて表示

### アクセシビリティ
- エラーメッセージは適切なARIA属性と共に表示
- スクリーンリーダーでも理解できる表現を使用
