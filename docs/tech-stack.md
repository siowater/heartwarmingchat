# 技術スタック

## 概要
本プロジェクトは無料枠を最大限活用し、0円運用を目指す技術スタックを採用しています。

## フロントエンド

### フレームワーク
- **Next.js** (React)
  - バージョン: 最新版（App Router使用）
  - 用途: 高速なSSR/SSG、ルーティング、API Routes
  - 理由: Vercelとの親和性が高く、無料枠で十分なパフォーマンス

### UIライブラリ
- **React**
  - バージョン: Next.jsに含まれる最新版
  - 用途: UIコンポーネント構築

### スタイリング
- **CSS Modules / Tailwind CSS**（検討中）
  - 用途: コンポーネントスタイリング
  - 理由: パステルカラーや丸みのあるデザインを柔軟に実装

### 状態管理
- **React Context API / Zustand**（検討中）
  - 用途: グローバル状態管理
  - 理由: 軽量で無料枠に適している

### フォーム管理
- **React Hook Form**
  - 用途: フォームバリデーション
  - 理由: 軽量でパフォーマンスが良い

## バックエンド・データベース

### データベース

### ストレージ

## 制約事項

### 無料枠の制限
- **Vercel Hobby Plan**
  - 帯域幅: 100GB/月
  - 関数実行時間: 100GB-時間/月
  - 同時実行数: 制限あり

- **Firebase Spark Plan**
  - Firestore: 50,000回読み取り/日、20,000回書き込み/日
  - Storage: 5GB保存、1GB/日のダウンロード
  - Authentication: 無制限（月間アクティブユーザー数制限なし）

### 対策
- データのクリーンアップ（一定期間後の自動削除）
- キャッシュ戦略の最適化
- 不要な読み取り/書き込みの削減
