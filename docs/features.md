# 機能一覧

## 画面一覧

### 1. トップページ（ホーム）
- **パス**: `/`
- **説明**: 投稿一覧を表示するメイン画面
- **表示内容**:
  - 投稿一覧（新着順/ランダム/リアクション順で切り替え可能）
  - 投稿作成ボタン
  - ナビゲーションメニュー
- **主要機能**:
  - 投稿一覧の表示・フィルタリング
  - 無限スクロール
  - リアクション・返信への遷移

### 2. 投稿詳細ページ
- **パス**: `/posts/[postId]`
- **説明**: 個別の投稿とその返信を表示する画面
- **表示内容**:
  - 投稿詳細
  - 返信一覧
  - 返信作成フォーム
  - リアクションボタン
- **主要機能**:
  - 投稿の表示
  - 返信の表示・作成
  - リアクションの送信

### 3. 投稿作成ページ
- **パス**: `/posts/new`
- **説明**: 新しい投稿を作成する画面
- **表示内容**:
  - 投稿作成フォーム
  - 文字数カウンター
  - 投稿ボタン
- **主要機能**:
  - 投稿内容の入力・バリデーション
  - NGワードフィルタリング
  - 投稿の保存

### 4. ログインページ
- **パス**: `/login`
- **説明**: ユーザー認証を行う画面
- **表示内容**:
  - SNS認証ボタン（Google、Twitter）
  - 匿名ログインボタン
  - 利用規約へのリンク
- **主要機能**:
  - Firebase Authentication連携
  - 認証後のリダイレクト

### 5. ユーザー設定ページ
- **パス**: `/settings`
- **説明**: ユーザー情報の設定画面
- **表示内容**:
  - ニックネーム設定
  - 通知設定（将来実装）
  - ログアウトボタン
- **主要機能**:
  - ニックネームの変更
  - 通知設定の変更（将来実装）

### 6. マイページ
- **パス**: `/profile`
- **説明**: 自分の投稿履歴と貢献度を表示する画面
- **表示内容**:
  - 自分の投稿一覧
  - 貢献度表示
  - 感謝の履歴
- **主要機能**:
  - 投稿履歴の表示
  - 貢献度の可視化

### 7. ランキングページ
- **パス**: `/ranking`
- **説明**: 貢献度ランキングを表示する画面
- **表示内容**:
  - 貢献度ランキング（上位50名）
  - 自分の順位
- **主要機能**:
  - ランキングの表示・更新

### 8. 利用規約ページ
- **パス**: `/terms`
- **説明**: 利用規約を表示する静的ページ
- **表示内容**:
  - 利用規約の全文

### 9. プライバシーポリシーページ
- **パス**: `/privacy`
- **説明**: プライバシーポリシーを表示する静的ページ
- **表示内容**:
  - プライバシーポリシーの全文

### 10. お問い合わせページ
- **パス**: `/contact`
- **説明**: お問い合わせフォームを表示する画面
- **表示内容**:
  - お問い合わせフォーム
  - 送信ボタン

## 処理一覧

### 認証関連処理

#### AUTH-001: ログイン処理
- **説明**: SNS認証または匿名認証でログイン
- **入力**: 認証プロバイダー情報
- **出力**: 認証トークン、ユーザー情報
- **エラーハンドリング**: 認証失敗時のエラーメッセージ表示

#### AUTH-002: ログアウト処理
- **説明**: セッションを終了し、ログアウト
- **入力**: なし
- **出力**: ログアウト成功フラグ
- **エラーハンドリング**: ログアウト失敗時のエラーメッセージ表示

#### AUTH-003: ニックネーム設定処理
- **説明**: ユーザーのニックネームを設定・更新
- **入力**: ニックネーム（最大50文字）
- **出力**: 更新成功フラグ
- **バリデーション**: 文字数チェック、NGワードチェック

### 投稿関連処理

#### POST-001: 投稿作成処理
- **説明**: 新しい投稿を作成し、Firestoreに保存
- **入力**: 投稿内容（最大1000文字）、ユーザーID
- **出力**: 投稿ID、作成日時
- **バリデーション**: 
  - 文字数チェック（1-1000文字）
  - NGワードフィルタリング
  - 1日あたりの投稿数制限チェック（最大10件）
- **エラーハンドリング**: バリデーションエラー、保存失敗時のエラーメッセージ表示

#### POST-002: 投稿一覧取得処理
- **説明**: 投稿一覧を取得（新着順/ランダム/リアクション順）
- **入力**: ソートタイプ、ページネーション情報
- **出力**: 投稿一覧、総件数
- **フィルタリング**: 削除フラグ、アーカイブフラグ、通報数のチェック

#### POST-003: 投稿詳細取得処理
- **説明**: 指定された投稿の詳細情報を取得
- **入力**: 投稿ID
- **出力**: 投稿詳細、返信一覧、リアクション情報
- **エラーハンドリング**: 投稿が存在しない場合のエラーメッセージ表示

#### POST-004: 投稿自動アーカイブ処理
- **説明**: 30日経過した投稿を自動的にアーカイブ（バッチ処理）
- **入力**: なし（スケジュール実行）
- **出力**: アーカイブされた投稿数
- **実行タイミング**: 1日1回（Cloud Functions等で実装）

#### POST-005: 投稿自動削除処理
- **説明**: 90日経過した投稿を自動的に削除（バッチ処理）
- **入力**: なし（スケジュール実行）
- **出力**: 削除された投稿数
- **実行タイミング**: 1日1回（Cloud Functions等で実装）

### 返信関連処理

#### REPLY-001: 返信作成処理
- **説明**: 投稿に対する返信を作成し、Firestoreに保存
- **入力**: 返信内容（最大500文字）、投稿ID、ユーザーID
- **出力**: 返信ID、作成日時
- **バリデーション**: 
  - 文字数チェック（1-500文字）
  - NGワードフィルタリング
  - 1投稿あたり1ユーザー最大1件の制限チェック
  - 自分の投稿への返信不可チェック
- **エラーハンドリング**: バリデーションエラー、保存失敗時のエラーメッセージ表示

#### REPLY-002: 返信一覧取得処理
- **説明**: 指定された投稿に対する返信一覧を取得
- **入力**: 投稿ID
- **出力**: 返信一覧（作成日時順）
- **フィルタリング**: 削除フラグ、通報数のチェック

### リアクション関連処理

#### REACT-001: リアクション送信処理
- **説明**: 投稿または返信に対するリアクションを送信
- **入力**: 対象タイプ（投稿/返信）、対象ID、リアクションタイプ、ユーザーID
- **出力**: リアクションID、作成日時
- **バリデーション**: 
  - 1ユーザーは1つの対象に対して1つのリアクションのみ
  - 自分の投稿・返信へのリアクション不可
- **エラーハンドリング**: バリデーションエラー、保存失敗時のエラーメッセージ表示

#### REACT-002: リアクション取消処理
- **説明**: 送信したリアクションを取り消し（削除）
- **入力**: リアクションID、ユーザーID
- **出力**: 取消成功フラグ
- **エラーハンドリング**: リアクションが存在しない場合のエラーメッセージ表示

#### REACT-003: リアクション集計処理
- **説明**: 投稿または返信に対するリアクション数を集計
- **入力**: 対象タイプ、対象ID
- **出力**: リアクション数（タイプ別）

### 貢献度関連処理

#### CONTRIB-001: 貢献度計算処理
- **説明**: ユーザーの貢献度を計算・更新
- **入力**: ユーザーID
- **出力**: 貢献スコア、返信数、リアクション数等
- **計算式**: 返信数×2 + リアクション数×1 + 受け取ったリアクション数×0.5

#### CONTRIB-002: ランキング取得処理
- **説明**: 貢献度ランキングを取得（上位50名）
- **入力**: なし
- **出力**: ランキング一覧、自分の順位
- **ソート**: 貢献スコアの降順

#### CONTRIB-003: 感謝の履歴取得処理
- **説明**: ユーザーが受け取った感謝（リアクション）の履歴を取得
- **入力**: ユーザーID
- **出力**: 感謝の履歴一覧

### 通知関連処理

#### NOTIF-001: 通知作成処理
- **説明**: リアクションや返信があった際に通知を作成
- **入力**: 通知タイプ、ユーザーID、対象ID
- **出力**: 通知ID、作成日時
- **トリガー**: リアクション送信時、返信作成時

#### NOTIF-002: 通知一覧取得処理
- **説明**: ユーザーの通知一覧を取得
- **入力**: ユーザーID
- **出力**: 通知一覧（作成日時順、最大100件）

#### NOTIF-003: 通知既読処理
- **説明**: 通知を既読にする
- **入力**: 通知ID、ユーザーID
- **出力**: 既読成功フラグ

#### NOTIF-004: 通知自動削除処理
- **説明**: 30日経過した通知を自動的に削除（バッチ処理）
- **入力**: なし（スケジュール実行）
- **出力**: 削除された通知数
- **実行タイミング**: 1日1回

### コンテンツモデレーション関連処理

#### MOD-001: NGワードフィルタリング処理
- **説明**: 投稿・返信内容をNGワードリストと照合
- **入力**: テキスト内容
- **出力**: フィルタリング結果（通過/ブロック）、該当NGワード
- **処理**: 完全一致、部分一致、正規表現によるチェック

#### MOD-002: 通報処理
- **説明**: 不適切な投稿・返信を通報
- **入力**: 対象タイプ、対象ID、通報理由、ユーザーID
- **出力**: 通報ID、作成日時
- **バリデーション**: 1ユーザーは1つの対象に対して1回のみ通報可能

#### MOD-003: 自動非表示処理
- **説明**: 通報数が一定数を超えた投稿・返信を自動的に非表示
- **入力**: なし（スケジュール実行またはリアルタイム）
- **出力**: 非表示にした投稿・返信数
- **閾値**: 投稿は5件、返信は3件

## API一覧

### 認証API

#### `POST /api/auth/login`
- **説明**: ログイン処理
- **リクエスト**: `{ provider: string, token?: string }`
- **レスポンス**: `{ userId: string, token: string }`
- **エラー**: `400 Bad Request`, `401 Unauthorized`

#### `POST /api/auth/logout`
- **説明**: ログアウト処理
- **リクエスト**: `{ token: string }`
- **レスポンス**: `{ success: boolean }`
- **エラー**: `401 Unauthorized`

### 投稿API

#### `GET /api/posts`
- **説明**: 投稿一覧取得
- **クエリパラメータ**: `sort=new|random|reactions`, `page=number`, `limit=number`
- **レスポンス**: `{ posts: Post[], total: number, page: number }`
- **エラー**: `400 Bad Request`

#### `GET /api/posts/[postId]`
- **説明**: 投稿詳細取得
- **レスポンス**: `{ post: Post, replies: Reply[], reactions: Reaction[] }`
- **エラー**: `404 Not Found`

#### `POST /api/posts`
- **説明**: 投稿作成
- **リクエスト**: `{ content: string }`
- **レスポンス**: `{ postId: string, createdAt: string }`
- **エラー**: `400 Bad Request`, `401 Unauthorized`, `429 Too Many Requests`

#### `PUT /api/posts/[postId]`（将来実装）
- **説明**: 投稿更新
- **リクエスト**: `{ content: string }`
- **レスポンス**: `{ success: boolean }`
- **エラー**: `400 Bad Request`, `401 Unauthorized`, `403 Forbidden`, `404 Not Found`

#### `DELETE /api/posts/[postId]`（将来実装）
- **説明**: 投稿削除
- **レスポンス**: `{ success: boolean }`
- **エラー**: `401 Unauthorized`, `403 Forbidden`, `404 Not Found`

### 返信API

#### `GET /api/posts/[postId]/replies`
- **説明**: 返信一覧取得
- **レスポンス**: `{ replies: Reply[] }`
- **エラー**: `404 Not Found`

#### `POST /api/posts/[postId]/replies`
- **説明**: 返信作成
- **リクエスト**: `{ content: string }`
- **レスポンス**: `{ replyId: string, createdAt: string }`
- **エラー**: `400 Bad Request`, `401 Unauthorized`, `404 Not Found`

### リアクションAPI

#### `POST /api/reactions`
- **説明**: リアクション送信
- **リクエスト**: `{ targetType: 'post'|'reply', targetId: string, reactionType: string }`
- **レスポンス**: `{ reactionId: string, createdAt: string }`
- **エラー**: `400 Bad Request`, `401 Unauthorized`, `404 Not Found`

#### `DELETE /api/reactions/[reactionId]`
- **説明**: リアクション取消
- **レスポンス**: `{ success: boolean }`
- **エラー**: `401 Unauthorized`, `403 Forbidden`, `404 Not Found`

#### `GET /api/reactions`
- **説明**: リアクション集計取得
- **クエリパラメータ**: `targetType=post|reply`, `targetId=string`
- **レスポンス**: `{ reactions: { [reactionType: string]: number } }`
- **エラー**: `400 Bad Request`

### ユーザーAPI

#### `GET /api/users/[userId]`
- **説明**: ユーザー情報取得
- **レスポンス**: `{ userId: string, nickname: string, contributionScore: number }`
- **エラー**: `404 Not Found`

#### `PUT /api/users/[userId]/nickname`
- **説明**: ニックネーム更新
- **リクエスト**: `{ nickname: string }`
- **レスポンス**: `{ success: boolean }`
- **エラー**: `400 Bad Request`, `401 Unauthorized`, `403 Forbidden`

#### `GET /api/users/[userId]/posts`
- **説明**: ユーザーの投稿一覧取得
- **レスポンス**: `{ posts: Post[] }`
- **エラー**: `404 Not Found`

#### `GET /api/users/[userId]/contribution`
- **説明**: 貢献度情報取得
- **レスポンス**: `{ contributionScore: number, replyCount: number, reactionCount: number, receivedReactionCount: number }`
- **エラー**: `404 Not Found`

### ランキングAPI

#### `GET /api/ranking`
- **説明**: 貢献度ランキング取得
- **レスポンス**: `{ ranking: UserRanking[], myRank?: number }`
- **エラー**: `401 Unauthorized`（自分の順位取得時）

### 通知API

#### `GET /api/notifications`
- **説明**: 通知一覧取得
- **レスポンス**: `{ notifications: Notification[] }`
- **エラー**: `401 Unauthorized`

#### `PUT /api/notifications/[notificationId]/read`
- **説明**: 通知既読処理
- **レスポンス**: `{ success: boolean }`
- **エラー**: `401 Unauthorized`, `403 Forbidden`, `404 Not Found`

### 通報API

#### `POST /api/reports`
- **説明**: 通報処理
- **リクエスト**: `{ targetType: 'post'|'reply', targetId: string, reason: string, details?: string }`
- **レスポンス**: `{ reportId: string, createdAt: string }`
- **エラー**: `400 Bad Request`, `401 Unauthorized`, `404 Not Found`
